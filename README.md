Курс-книга для русскоязычного читателя: главы читаются подряд, упражнения проверяют себя сами, прогресс хранится прямо в браузере. К концу — уверенный уровень B1: чтение, грамматика, словарь и бытовые темы.

---

## Для кого

Для тех, кто начинает армянский с нуля и хочет систему, а не разрозненные уроки. Нужен только браузер и желание заниматься регулярно — всё объясняется на русском, с опорой на знакомую логику.

## Что внутри

- **58 уроков** — от букв до сложного синтаксиса и тем уровня B1.
- **Словарь курса** (`vocabulary.html`) — почти 2900 слов с чекбоксами «выучил / не выучил», разбивкой по темам и уровням.
- **Интерактивный тренажёр-карточки** — повторение слов прямо в книге.
- **Грамматические шпаргалки** — алфавит, склонения, глаголы, синтаксис, словообразование, глоссарий терминов.
- **Прогресс в браузере** — отмеченные уроки сохраняются между сессиями.
- **Без установки** — чистый HTML, работает офлайн.

## Программа курса

| Блок | Темы | Уроки |
|-----:|------|------|
| **Алфавит и чтение** | буквы, чтение, первые фразы | 1–4 |
| **Базовое общение** | «быть», артикль, множественное, числа, настоящее время | 5–11 |
| **Падежная система** | первые падежи, родительный/дательный, склонения | 12–19 |
| **Времена** | имперфект, аорист, будущее, календарь и время | 20–24 |
| **Расширение** | предлоги и послелоги, сравнение, модальность, местоимения | 25–29 |
| **Бытовые темы** | здоровье, ресторан, дорога, телефон, работа | 30–34 |
| **Сложные формы** | перфект, плюсквамперфект, условное, сослагательное | 35–39 |
| **Причастия и залог** | причастия, страдательный залог, каузатив | 40–43 |
| **Синтаксис** | придаточные, косвенная речь, условные предложения | 44–49 |
| **Практика и B1** | жильё, документы, письмо, чтение, стратегии, итог B1 | 50–58 |

## Справочники

Открыл — увидел правило в таблице — вспомнил. Удобно держать под рукой:
алфавит, артикль и число, склонения, глаголы, неправильные глаголы, послелоги, местоимения, синтаксис, словообразование, **глоссарий** грамматических терминов и **список ресурсов**.

## Как открыть

Книга — это набор статических HTML-файлов, ничего устанавливать не нужно.

- **Локально:** открой [`index.html`](index.html) в браузере.
- **Онлайн:** опубликуй папку через GitHub Pages и поделись ссылкой.

Начать: [Урок 1 — Алфавит, часть 1](lessons/0001-alphabet-1.html).
