# Восточноармянский: A0–B1

Учебник для русскоязычного взрослого: 58 основных уроков и 38 дополнительных занятий. Армянская графика используется с первого дня. В учебнике нет русской транскрипции; в справочном словаре она сохранена.

Начало: [главная](index.html), [полная программа](reference/curriculum.html), [чтение, речь и Конституция](tracks.html).

## Содержание

| Уровень | Основные уроки | Дополнительные | Всего занятий |
|---|---:|---:|---:|
| A1 | 16 | 10 | 26 |
| A2 | 18 | 14 | 32 |
| B1 | 24 | 14 | 38 |
| Всего | 58 | 38 | 96 |

Дополнения: 15 больших чтений, 3 речевые мастерские, 8 занятий по Конституции, 9 накопительных повторений, 3 контрольные точки. Каждый основной урок дополнен чтением, заданиями и ответом вслух. В каждом основном уроке есть цепочка из трёх преобразований. Во всех повторениях после начала конституционного трека есть проверяемый блок по уже изученному материалу. Для активных слов запланировано пять возвращений, включая повторение после конца маршрута. Контролируемый активный набор содержит 331 слово и сочетание; полный словарь — 2869 записей.

[Экзаменационный тренажёр](exam.html) содержит 64 **авторских** вопроса с пояснениями и ссылками на статьи. Правила пробника проверены 10.09.2026 по [постановлению N 97-Н](https://www.arlis.am/hy/acts/219991): 33 вопроса, 60 минут, минимум 17 верных. Это не официальный банк билетов. Текущая Конституция, процедура проверки и языковой уровень — разные предметы проверки.

Прохождение страниц не подтверждает B1. Чтение, письмо и речь оцениваются в контрольных точках; аудирование требует отдельной практики с незнакомой устной речью. Ориентир нагрузки: 2–3 часа, пять дней в неделю, с чередованием блоков и повторением. Один урок может занимать несколько сессий.

## Открытие и сохранение

Открой `index.html` либо запусти из этой папки `python3 -m http.server 8765 --bind 127.0.0.1` и перейди на `http://127.0.0.1:8765/`. Локальный сервер даёт всем страницам общее хранилище; при открытии через `file:` поведение зависит от браузера.

Страницы, задания и учебный банк работают без внешних сервисов. Для внешнего аудио и источников нужен интернет. [Прогресс](progress.html) сохраняет уроки, слова, чтение, речь, черновики, самооценку и экзаменационную статистику. Экспорт версии 2 включает все эти разделы; импорт принимает также старую версию 1. Незавершённая попытка экзамена остаётся в текущем браузере. Таймер идёт и при закрытой вкладке.

## Печать карточек

В [тренажёре слов](vocabulary.html) нажми «Распечатать карточки». В [редакторе](print-cards.html) можно выбрать число карточек на А4, настроить столбцы и отдельно шрифт, размер и жирность слова в центре и перевода в углу. Настройки применяются ко всем листам. Кликни по карточке для ввода; словарь ищет по армянскому, русскому и транскрипции. Выбранное слово автоматически заполняет перевод, оба текста можно исправить вручную. Длинный текст переносится и при необходимости уменьшается до границ своей области.

«Добавить лист» создаёт следующую страницу; кнопки перехода и список листов позволяют переключаться между ними. При изменении числа карточек заполненные ячейки сохраняются по порядку и при необходимости занимают дополнительные листы; пустые хвостовые листы убираются. Черновик автоматически сохраняется в текущем браузере отдельно от учебного прогресса. «Скачать файл» сохраняет все листы и настройки в JSON; «Открыть файл» возвращает их в редактор. Этот файл нужен для резервной копии и дальнейшего редактирования, PDF предназначен для печати.

«Печать / PDF» печатает все листы. В диалоге выбери А4, масштаб 100% и отключи колонтитулы; для файла выбери сохранение в PDF. Линии разреза входят в печать, элементы редактора и подсказки пустых ячеек скрыты. Поля бумаги составляют 10 мм.

## Поддержка курса

- `lessons/`, `practice/`, `reference/`, `assets/` — страницы и клиентская логика.
- `content/` — авторские тексты, активные примеры и банк вопросов; исходник полного словаря — `assets/vocab-data.js`.
- `tools/build_course.py` — сборка дополнений и программы без сетевых запросов, нужны Python 3 и Node.js. Сохраняет исходные URL и номера уроков.
- `tools/inventory.py` — проверка всех локальных ссылок, якорей, HTML id и структуры словаря.
- `tools/content-test.py` — проверка полноты чтений, цепочек, активных примеров и повторений, связи заданий со страницами.
- `tools/apply_vocabulary_corrections.cjs` — применяет проверенные поправки словаря из `content/vocabulary-corrections.json`, сохраняя номера записей.
- `tools/trainer-test.cjs`, `tools/course-test.cjs`, `tools/exam-state-test.cjs` — проверки словарного тренажёра, экзамена и переноса прогресса.
- `docs/` — задание, аудит, программа, план и итоговый отчёт. `logs/` — журнал работы.

После изменения `content/` выполни `python3 tools/build_course.py`, затем `python3 tools/inventory.py`, `python3 tools/content-test.py`, `node tools/trainer-test.cjs` `node tools/course-test.cjs` и `node tools/exam-state-test.cjs`. HTML основных уроков редактируется вне помеченных блоков `COURSE-PRACTICE` и `COURSE-NAV`. Номера слов и ключи прогресса нельзя перенумеровывать.

Прежняя папка `progress/` была архивом разработки. Она удалена после переноса полезной проверки тренажёра; пользовательский прогресс в браузере от этого не меняется. Внешняя папка содержит только этот репозиторий `result/`. Настройка Cloudflare сохранена, служебные материалы исключены из статических ресурсов через `.assetsignore`.

Подробная сверка задания и границы проведённой проверки: [итоговый отчёт](docs/final-report.md).
